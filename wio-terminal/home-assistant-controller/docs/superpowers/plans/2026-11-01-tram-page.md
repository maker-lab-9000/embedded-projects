# Tram Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wio Terminal firmware that shows the live Kuckhoffstr. M1 tram page from Home Assistant, with button C toggling the display.

**Architecture:** One Arduino sketch (`firmware/m1_tram/`) with header-only modules. Pure logic (time parsing, HA message → model, history) is host-testable with clang++ + ArduinoJson; network and drawing are verified on the device over serial and by the user looking at the screen. A single WebSocket to HA carries `subscribe_entities` updates and periodic `history/history_during_period` requests.

**Tech Stack:** Seeed SAMD core 1.8.6, rpcWiFi 1.1.0, ArduinoWebsockets 0.5.4 (or hand-written fallback), ArduinoJson 7.4.3, bundled TFT_eSPI, arduino-cli.

**Spec:** `docs/superpowers/specs/2026-11-01-tram-page-design.md`

All paths below are relative to `wio-terminal/home-assistant-controller/`.

## Global Constraints

- FQBN `Seeeduino:samd:seeed_wio_terminal`; port `/dev/cu.usbmodem14101`.
- HA `ws://192.168.178.137:8123/api/websocket`; credentials only from gitignored `firmware/m1_tram/secrets.h` (`WIFI_SSID`, `WIFI_PASS`, `HA_HOST`, `HA_PORT`, `HA_TOKEN`).
- Entities: `sensor.kuckhoffstr_berlin`, `input_number.home_m1_tram_minutes_between_trams`, `sensor.home_m1_tram_last_departed`.
- On `auth_invalid`: never retry until reset; show "Token rejected".
- Reconnect backoff: 5 s, doubling, cap 300 s; reset to 5 s after `auth_ok`.
- History: last 24 h, refresh every 10 min, max 96 points (keep latest).
- Keep at most 3 non-cancelled departures.
- Button C (`WIO_KEY_C`) toggles backlight; A, B, joystick wake only.
- `loop()` must not block > ~50 ms except during a (backed-off) connect attempt.
- `Serial.printf` truncates at ~80 chars: split long lines.
- **Testing against HA:** at most one auth attempt per manual test run; if auth fails, stop and report — do not loop (IP ban risk).

## Review Focus

1. HA restart / WiFi drop mid-session → reconnects with backoff, resubscribes, re-fetches history, screen keeps old data meanwhile. (Task 4 serial test.)
2. Departures empty, or all cancelled → "No trams scheduled", never a stale countdown. (Task 3 test `empty_and_cancelled`.)
3. A departure whose timestamp is already past but still listed → shows "now", not a negative number. (Task 2 test `countdown_clamps`.)
4. Clock not yet synced (NTP pending) → countdowns and "ago" show "--", not garbage based on epoch 0. (Task 2 test `unsynced_time`.)
5. History reply empty or with non-numeric states (`unavailable`) → chart shows "No data" / skips those points. (Task 3 test `history_skips_non_numeric`.)

### Task 2: Time utilities (host-tested)

**Files:**
- Create: `firmware/m1_tram/timeutil.h`
- Create: `test/test_main.cpp`, `test/run.sh` (`clang++ -std=c++17 -I firmware/m1_tram -I ~/Documents/Arduino/libraries/ArduinoJson/src test/test_main.cpp -o "$TMPDIR/tram_tests" && "$TMPDIR/tram_tests"`; minimal `CHECK(cond)` macro, nonzero exit on failure)

**Interfaces — Produces:**
- `bool parseIso8601(const char* s, uint32_t& epochUtc)` — accepts `2026-11-01T22:58:00+01:00`, `2026-11-01T21:35:00+00:00`, `…Z`, and fractional seconds `21:48:56.370205+00:00`.
- `int32_t berlinOffset(uint32_t epochUtc)` — 3600 or 7200 (EU rule: last Sunday Mar/Oct 01:00 UTC).
- `void formatClock(uint32_t epochUtc, char* buf, size_t n)` — Berlin `HH:MM`.
- `void formatAgo(uint32_t now, uint32_t then, char* buf, size_t n)` — `"12 sec ago"`, `"3 min ago"`, `"2 h ago"`; `now==0` (unsynced) or `then==0` → `"--"`.
- `void formatCountdown(uint32_t now, uint32_t dep, char* buf, size_t n)` — `"in 4 min"` (floor of minutes), `<60 s` or past → `"now"`; `now==0` → `"--"`.

- [ ] **Step 1: Failing tests** in `test/test_main.cpp`:
  - `parseIso8601("2026-11-01T22:58:00+01:00")` == 1793570280; `"2026-11-01T21:35:00+00:00"` == 1793568900; fractional variant parses; `"N/A"` → false.
  - `berlinOffset` of 2026-03-29T00:59Z == 3600, 01:00Z == 7200; 2026-10-25T00:59Z == 7200, 01:00Z == 3600.
  - `formatClock(1793570280)` == `"22:58"`.
  - `countdown_clamps`: dep = now − 30 → `"now"`; dep = now + 59 → `"now"`; dep = now + 245 → `"in 4 min"`.
  - `unsynced_time`: `formatCountdown(0, x)` and `formatAgo(0, x)` → `"--"`.
  - `formatAgo(now, now-12)` == `"12 sec ago"`, `-180` → `"3 min ago"`, `-7300` → `"2 h ago"`.
- [ ] **Step 2:** `test/run.sh` → fails to compile (no `timeutil.h`).
- [ ] **Step 3:** Implement `timeutil.h` (days-from-civil for epoch; no `mktime`/TZ dependency).

### Task 3: Tram model — HA messages into state (host-tested)

**Files:**
- Create: `firmware/m1_tram/tram_model.h`
- Modify: `test/test_main.cpp`

**Interfaces — Consumes:** `parseIso8601` (Task 2). **Produces:**
```cpp
struct Departure { char line[6]; char dir[40]; char time[6]; uint32_t epoch; int16_t delayMin; uint16_t color565; };
struct GapPoint  { uint32_t t; float v; };
struct TramState {
  Departure dep[3]; uint8_t depCount; bool depKnown;
  float gapMin; bool gapKnown;
  uint32_t lastDeparted;            // 0 = unknown
  GapPoint hist[96]; uint8_t histCount; bool histKnown;
  uint8_t dirty;                    // bit flags below
};
enum : uint8_t { DIRTY_NEXT = 1, DIRTY_GAP = 2, DIRTY_LAST = 4, DIRTY_CHART = 8 };
void tramApplyEvent(TramState& s, JsonVariantConst event);    // subscribe_entities "event" object ({"a":…} or {"c":…})
void tramApplyHistory(TramState& s, JsonVariantConst result); // history_during_period "result"
uint16_t hexTo565(const char* hex);                            // "#D82020"; bad input → 0xF800 red
```
Unknown entity ids are ignored. In `"c"` updates, only fields present under `"+"` are applied (`"s"`, `"a".departures`).

- [ ] **Step 1: Failing tests** (JSON literals in the test, shaped like the real payloads from the spec):
  - initial `{"a":{…all 3 entities…}}` with 4 departures incl. one `cancelled:true` → `depCount==3`, first is M1, direction copied (truncated to 39 chars), `delayMin` = delay/60, `color565 == hexTo565("#D82020")`; `gapMin==20.0`; `lastDeparted==1793568900`; `dirty == DIRTY_NEXT|DIRTY_GAP|DIRTY_LAST`.
  - `empty_and_cancelled`: departures `[]` → `depCount==0, depKnown==true`; all cancelled → `depCount==0`.
  - change `{"c":{"input_number.home_m1_tram_minutes_between_trams":{"+":{"s":"21.0"}}}}` → `gapMin==21`, only `DIRTY_GAP` newly set, departures untouched.
  - gap state `"unavailable"` → `gapKnown==false`.
  - `history_skips_non_numeric`: result `{"input_number.…":[{"s":"20.0","lu":1793500000.1},{"s":"unavailable","lu":…},{"s":"30","lu":…}]}` → `histCount==2`, `DIRTY_CHART` set; empty result → `histCount==0, histKnown==true`.
  - 120 numeric points → `histCount==96` and last point is the newest.
- [ ] **Step 2:** Run → fails.
- [ ] **Step 3:** Implement `tram_model.h`. Note `minimal_response` history: first item has `lu` (float epoch), later items may have only `lu`; use `lu`, fall back to `lc`.

```cpp
enum HaStatus : uint8_t { HA_OFFLINE, HA_CONNECTING, HA_CONNECTED, HA_AUTH_REJECTED };
void haInit(TramState* s);
```

Message ids: 1 = subscribe_entities, then 2, 3, … for history requests (track the pending id; ignore stale results). JSON filter on incoming: keep `type`, `id`, `success`, `event`, `result`.

### Task 5: Tram page drawing, display sleep

**Files:**
- Create: `firmware/m1_tram/page_tram.h` — `void tramDraw(TFT_eSPI& tft, TramState& s, uint32_t now, HaStatus st, bool full);`
- Create: `firmware/m1_tram/ui.h` — page table (`struct Page { const char* name; void (*draw)(bool full); }`, one entry now), button handling, backlight
- Modify: `firmware/m1_tram/m1_tram.ino` — replace dump with UI

Layout per spec mockup: header 0–24 px (stop name, status dot, Berlin clock), next-tram block 24–100, chart 100–210, last-departed row 210–240. Dark background `0x18E3`-ish, HA-like text colors. Redraw only regions whose `dirty` bit is set, plus the countdown/clock/ago strings once per second (draw into a `TFT_eSprite` per row to avoid flicker if RAM allows; else fill-then-draw). Chart: step line, y range = [min−2, max+2] rounded, 3 gridlines with labels, x labels `-24h -18h -12h -6h now`; the step extends to `now` at the last value; `"No data"` when `histCount==0`. Status text when not connected: `"Connecting…"`, `"Offline"`, `"Token rejected"`.

Buttons (debounced, edge-triggered): `WIO_KEY_C` toggles `LCD_BACKLIGHT`; when dark, `WIO_KEY_A`, `WIO_KEY_B`, any `WIO_5S_*` turn it on (and are otherwise consumed). Skip drawing while dark; force a full redraw on wake.
